# Next Mile Tracker

A desk display for the ESP32-2432S028R "Cheap Yellow Display" that shows a runner's Strava miles for the current year, a goal bar (beat last year by default, or a custom goal), and their last run. Built by DS3design for a Next Mile Apparel / Pacegiving raffle prize.

Boot: DS3design intro clip, Next Mile Apparel splash, then setup or the mileage screen.

## Layout

| Path | What |
| --- | --- |
| `firmware/` | PlatformIO project (Arduino, LovyanGFX). Envs `cyd_ili9341` and `cyd_st7789` for the two panel variants CYD clones ship with. |
| `firmware/data/` | LittleFS image: `intro.bin` (JPEG frames) and `nextmile.jpg` splash. |
| `docs/` | GitHub Pages: setup guide (`index.html`) and the Strava OAuth hand-off page (`link/`). |
| `sim/` | Desktop renderer for the screens (`./build.sh`, needs `libsdl2-dev`). |
| `case/` | Laser-cut SVGs (red = cut, black = engrave) for 3 mm basswood. Generated by `tools/make_case.py`. |
| `card/` | Printable 4x6 in setup card. |
| `tools/` | Generators for fonts, assets, root certificates, case and card. |

## Strava app

1. Create an API app at https://www.strava.com/settings/api (needs a Strava subscription on the creator's account).
2. Set **Authorization Callback Domain** to `ds3design.github.io`.
3. Raise the athlete capacity to 10 on the app dashboard (new apps start at 1).
4. Copy `firmware/src/secrets.example.h` to `firmware/src/secrets.h` and fill in the client ID and secret. `secrets.h` is git-ignored and only ever lives in the flashed firmware.

## Flashing

```sh
cd firmware
pio run -e cyd_ili9341 -t upload      # or cyd_st7789 if colours/orientation look wrong
pio run -e cyd_ili9341 -t uploadfs    # intro clip + splash
```

## How linking works

The tracker serves `http://<ip>/link`, which sends the phone to Strava's authorize page with `state=<tracker ip>`. Strava redirects to `docs/link/` on GitHub Pages, which forwards the one-time code to `http://<ip>/exchange` on the home network. The tracker swaps it for tokens and refreshes them itself from then on. Syncing reads the latest 30 activities every 30 minutes and re-reads the whole year once a day, so edits and deletions show up.
