Link Apple Watch

Apple Watch runs live in the Health app on your iPhone, so an iPhone Shortcut sends your miles to the tracker. Set it up once:

  1. Open the Shortcuts app → Automation → + → Time of Day, every day (for example 9 PM), Run Immediately.
  2. Add Find Health Samples: Workouts, Type is Running, Start Date is in this year. Then Calculate Statistics → Sum of Distance (miles).
  3. Add Get Contents of URL: Method POST, Request Body JSON with keys year, miles (the sum), runs (count) and the URL below.

Your iPhone must be home on the same WiFi when it runs. A ready-made Shortcut link is on the Next Mile Tracker help page.
