Next Mile Tracker

Your tracker shows how many miles you've run this year, straight from Strava. It works with any watch or app that syncs to Strava (Garmin, Coros, Apple Watch, Polar, Suunto, the Strava app).

Setup (about 3 minutes)

  1. Plug the tracker into a USB phone charger.
  2. When it shows Let's get connected, scan the QR code on the screen with your phone camera, or open your phone's WiFi settings and join NextMile-Tracker.
  3. A setup page opens. Tap Configure WiFi, choose your home network and type its password.
  4. The screen shows a new QR code. Scan it (your phone must be back on your home WiFi), then tap Authorize on Strava. Leave the box for private activities ticked so every run counts.
  5. That's it. The tracker checks Strava every 30 minutes and starts a fresh count every January 1.

Using it

  • Tap the screen to show a QR code for the settings page, where you can set your own yearly goal, change the name shown, the brightness, the time zone, or count walks and hikes too. Tap again to go back.
  • Goal bar: by default your goal is to beat last year's miles by about 10%. Set your own number on the settings page any time.
  • Hold the screen for 10 seconds to erase WiFi, Strava and settings and start setup again (for example, before giving it to someone else).
  • A small red dot in the corner means the last update didn't reach Strava. It retries on its own.

Troubleshooting

I can't see the NextMile-Tracker network

Make sure the screen says Let's get connected. If it says WiFi not found, tap the screen once to reopen setup.

My WiFi isn't in the list

The tracker only works on 2.4 GHz WiFi. Most routers have both; if yours shows two names, choose the one without "5G". Mesh systems usually work as-is.

Strava says "Authorize" but then the page won't load

Your phone must be on the same home WiFi as the tracker (not cellular data). Switch WiFi on, then tap Finish linking on the page, or scan the code on the tracker again.

A run is missing

Check it shows in Strava as a Run, Trail Run or Virtual Run. The tracker updates every 30 minutes; you can also tap the screen, scan the code and press Update now.

I moved or got a new router

If the screen says WiFi not found or shows a red NO WIFI, tap it once and the setup network NextMile-Tracker comes back so you can pick your new WiFi. Your Strava link and goal are kept.
